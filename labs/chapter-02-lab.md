# Chapter 2 Lab: Machine Learning Foundations Part 1: Supervised & Unsupervised Learning

**Estimated time:** 15 minutes

## Exercise

Paradigm ID Drill: given 8 dataset descriptions such as 'customer purchase history with no labels' or 'house square footage paired with sale price', label each as supervised-regression, supervised-classification, or unsupervised-clustering

## Key takeaway

Supervised learning uses labeled data to predict a number (regression) or a category (classification), while unsupervised learning finds structure in unlabeled data through clustering.

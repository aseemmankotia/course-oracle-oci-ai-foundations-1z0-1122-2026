# Chapter 11 Lab: OCI Generative AI Service & Oracle Database 23ai

**Estimated time:** 15 minutes

## Exercise

Capability Mapping Exercise: given 6 enterprise scenarios, such as 'build a chatbot grounded in company documents using OCI's generative AI stack' or 'run semantic similarity search directly inside an existing Oracle Database', decide whether OCI Generative AI service or Oracle Database 23ai AI Vector Search is the primary tool

## Key takeaway

The OCI Generative AI service provides foundation models, prompting, fine-tuning, and RAG at the compute layer, while Oracle Database 23ai AI Vector Search provides in-database semantic retrieval that can feed those generative pipelines.

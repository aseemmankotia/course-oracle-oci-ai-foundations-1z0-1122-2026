## Chapter 2: Machine Learning Foundations Part 1: Supervised & Unsupervised Learning — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Supervised learning requires what type of data? | Labeled data — each example has a known input and correct output. Exam tip: presence of labels = supervised. |
| 2 | Unsupervised learning requires what type of data? | Unlabeled data — no predefined output or target value. Exam tip: absence of labels = unsupervised. |
| 3 | What type of output does regression produce? | A continuous numeric value (e.g., price, temperature, sales amount). Exam tip: 'predict a number' = regression. |
| 4 | What type of output does classification produce? | A categorical/discrete label (e.g., spam/not spam, disease/no disease). Exam tip: 'predict a category or class' = classification. |
| 5 | What is the purpose of clustering? | Group unlabeled data into natural clusters based on similarity, with no predefined categories. Exam tip: 'discover groups' with no labels = clustering. |
| 6 | Key differentiator the exam tests: supervised vs unsupervised? | Check whether the data has labeled outcomes. Labels present → supervised (regression or classification). Labels absent → unsupervised (clustering). |
| 7 | Example: Predicting the exact sale price of a house | Supervised learning — Regression (continuous numeric output). |
| 8 | Example: Classifying customer churn as Yes/No | Supervised learning — Classification (categorical output). |
| 9 | Example: Segmenting customers with no predefined groups | Unsupervised learning — Clustering (pattern extraction from unlabeled data). |
| 10 | Exam trap: question uses the word 'grouping' | 'Grouping' doesn't always mean clustering. If the groups/labels are already known and provided in training data, it's supervised classification, not unsupervised clustering. |
| 11 | How to choose regression vs classification once you know labels exist | If the label is a continuous number → regression. If the label is a category/class → classification. |
| 12 | Exam trap: numeric-looking labels like 0/1 | A binary numeric label (e.g., fraud=1/0) still represents a category, not a continuous measure — this is classification, not regression. |

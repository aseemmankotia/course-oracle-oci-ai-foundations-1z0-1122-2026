## Commonly Confused Pairs (Cross-Domain)
| Pair | Key Differentiator |
|---|---|
| OCI Vision vs Document Understanding | Vision = images/objects/basic OCR. Document Understanding = structured forms/tables/key-value extraction. |
| OCI Anomaly Detection vs Forecasting | Anomaly = flags outliers now. Forecasting = predicts future values. |
| OCI Language vs Speech | Language = text NLP. Speech = audio-to-text and text-to-audio. |
| Data Science Jobs vs Model Deployment | Jobs = batch scripts, no endpoint. Model Deployment = live REST inference endpoint. |
| Fine-tuning vs Prompt Engineering | Fine-tune with labeled data for narrow/specialized domains. Prompt-engineer for fast, low-cost, general adjustments. |
| On-Demand vs Dedicated AI Cluster | On-Demand = shared, pay-per-use. Dedicated = reserved capacity, required for fine-tuning/production throughput. |
| Supervised vs Unsupervised Learning | Supervised = labeled data, known outcomes. Unsupervised = unlabeled, pattern discovery. |

## Elimination Strategy
1. Read the full scenario — note every stated constraint (cost, scale, latency, data type).
2. Eliminate options that reference deprecated/wrong-modality services immediately.
3. Of remaining plausible options, pick the one satisfying ALL constraints — not just most.
4. Ignore answer length, alphabetical order, or terms recalled from other questions.

## Flag-and-Review Protocol
1. First pass: answer everything you're sure of.
2. Uncertain? Select your best guess, flag it, move on — never leave blank.
3. Second pass: revisit only flagged questions with remaining time.
4. Stop second-guessing confident answers unless you find a clear factual error.
